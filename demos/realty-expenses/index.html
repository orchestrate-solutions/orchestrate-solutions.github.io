What This Replaces

Before (Manual — ~45 min/week):

  1. Log into Marion Community Bank online banking
  2. Export transaction CSV for each of 3 accounts
  3. Open each CSV, manually reformat columns (4 transformations per file)
  4. Copy/paste into the correct Google Sheet tab
  5. Manually categorize each transaction
  6. Assign expenses to the correct agent

After (Automated — ~30 seconds):

  1. Click "Sync" — data flows automatically from bank → spreadsheet
  2. Review categorized transactions (edit if needed)
  3. Done ✓
